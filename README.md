# ВгадайПісню — інструкція

## Запуск
1. Розпакуй архів.
2. Відкрий папку `vgadai_pisniu` у Visual Studio Code.
3. Відкрий `index.html` через розширення Live Server (рекомендовано) або просто у браузері.
4. Потрібен інтернет для завантаження YouTube IFrame Player API та шрифтів.

## Важливо: додавання музики з YouTube
У `script.js` знайди масив `songs`. У кожного треку є поле `videoId`, зараз воно порожнє навмисно — не підставляй випадкові ID.

Як знайти ID:
- Відкрий потрібне відео на YouTube.
- Для посилання `https://www.youtube.com/watch?v=AbCdEf12345` ID — `AbCdEf12345`.
- Встав ID у відповідний запис, наприклад: `videoId: "AbCdEf12345"`.
- `start` — секунда, з якої починати фрагмент.

Важливо:
- Обирай офіційні відео/записи, які дозволяють вбудовування.
- Не всі ролики можна відтворити у вбудованому плеєрі.
- YouTube вимагає показувати вбудований плеєр і дотримуватися його правил; цей сайт залишає плеєр видимим у правому нижньому куті.
- YouTube Music Premium не надає API-доступу до аудіофайлів і не дає права витягувати музику.
- Для публічного сайту перевіряй права та умови використання музичних записів.

## Додавання власного треку
Скопіюй один об'єкт у масив `songs`:
```js
{ title: "Назва пісні", artist: "Виконавець", category: "classic", videoId: "ID_З_YOUTUBE", start: 30 }
```
Категорії: `classic`, `modern`, `rock`, `meme`.
Для запуску гри в обраній категорії потрібно щонайменше 4 записи з непорожнім `videoId`.
